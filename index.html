حتى الآن

مسؤولة عن تشغيل وصيانة منظومات الحاسب الآلي، إدارة شبكات المعلومات، وتوفير الدعم التقني المتواصل لضمان سير العمل بكفاءة داخل قطاعات الوزارة، بالإضافة إلى متابعة مشروعات التحول الرقمي وتطوير القواعد البياناتية.

  • إدارة وصيانة شبكات الحاسب الآلي والمعدات الإلكترونية.
  • تقديم الدعم الفني المتقدم لحل أعطال البرمجيات والأجهزة.
  • المشاركة في تحديث وتأمين البنية التكنولوجية والمواقع الإدارية.
القدرات والتمكن التقني

المهارات والتقنيات

إدارة الشبكات

تصميم وإدارة الشبكات المحلية (LAN/WAN)، تكوين أجهزة الراوتر والسويتشات، وضمان أمن الاتصال.

قواعد البيانات

التعامل مع أنظمة إدارة قواعد البيانات، استرجاع وتحليل البيانات، وتنظيم حفظ الملفات الرقمية.

البرمجة والأسمتة

استخدام لغات مثل Python و JavaScript و HTML/CSS لتطوير أدوات داخلية وتسهيل مهام العمل.

صيانة الهاردوير والصวф트

تشخيص أعطال الحواسيب، ترقية الأنظمة، وصيانة الأجهزة والمعدات الإلكترونية بدقة وكفاءة.
